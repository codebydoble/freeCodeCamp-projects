Design a Movie Review Page
Build an app that is functionally similar to this example project. Try not to copy the example project, give it your own personal style.

Objective: Fulfill the user stories below and get all the tests to pass to complete the lab.

User Stories:

[ok] You should have a main element.
[ok] Inside the main element, you should have an h1 element for the movie title.
[ok] Below the h1 element, you should have an img element displaying the movie cover. Your img element should have a descriptive alt text describing the image. You are free to use the following image if you like: https://cdn.freecodecamp.org/curriculum/labs/rise-beyond-2.png.
[ok] You should have a p element containing a brief movie description.
[ok] You should have another p element to display the movie rating. Within it, you should have these items in the listed order:
A strong element with the text Movie Rating:.
A span element with an aria-hidden attribute set to true containing a visual representation of the rating using stars ⭐⭐⭐⭐⭐⭐⭐⭐⭐☆.
A numerical value, representing the rating, in parentheses (e.g. 9.2/10) after the span.
[ok] You should have an h2 element with the text Cast Members.
[ok] You should have a ul element.
Inside the ul element, you should have multiple li elements each containing a strong element for the actor's name followed by the corresponding character name preceded by the text as. (e.g., James Holloway as Ethan Carter).
