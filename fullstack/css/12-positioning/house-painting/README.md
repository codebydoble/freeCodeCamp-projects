# Build a House Painting

Build an app that is functionally similar to this example project. Try not to copy the example project, give it your **own personal style**.

In this lab, you will use HTML to create the structure of a house. Then, you will use CSS positioning to arrange the elements of your house like windows and doors.

**Objective**: Fulfill the user stories below and get all the tests to pass to complete the lab.

## User Stories:

1. [x] You should have a div with an id of house.
2. [x] Your #house should have a position set to relative so its children can be positioned with respect to it.
3. [x] Your #house should have a width of 500px and a height of 400px. Do not set minimum or maximum values.
4. [x] Your #house should have a background color and a border set.
5. [x] You should have five div elements inside #house with the following id values: chimney, roof, window-1, window-2, and door.
6. [x] All of the immediate children of the #house should have a position of absolute.
7. [x] #roof, #chimney, #window-1, #window-2, and #door should have a width, height, border, and background color set.
8. [x] Your #roof should have a top value of 0.
9. [x] Your #door should be placed at the bottom of your house.
10. [x] Your windows should be placed below your #roof and at least higher than one third of your #door's height.
11. [x] Both your windows and your door should have either left or right set to a value that places them within the house borders.
12. [x] Your #chimney should have a top value that puts it at the top of your #house.
13. [x] Your #chimney should have a z-index that puts it behind the house.

**Note**: Be sure to link your stylesheet in your HTML to apply your CSS.
