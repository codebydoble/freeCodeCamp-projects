# Build a Stylized To-Do list

Build an app that is functionally similar to this example project. Try not to copy the example project, give it your own personal style.
In this lab, you will practice the different styles that can be applied to links when they are hovered over, focused, clicked, and visited.

**Objective**: Fulfill the user stories below and get all the tests to pass to complete the lab.

## User Stories:

1. [x] You should have one unordered list with the class todo-list.
2. [x] Inside the unordered list, you should have four list items.
3. [x] Inside each list item, there should be:
    - An input element with the type checkbox and id set to a unique value.
    - A label element with the for attribute set to the corresponding input element's id.
    - An unordered list with the class sub-item.
    - A list item with an anchor element in it. The anchor should have the class sub-item-link, a valid href value, and a target value that makes the link open in a new tab.
4. [x] Your anchor elements shouldn't have any default text decoration.
5. [x] You should set the text color of the links to a color of your choice.
6. [x] When your links are visited, the color should change to another color of your choice.
7. [x] When your links are hovered over, the color should change to another color of your choice.
8. [x] When your links are focused, there should be a colored outline around the link.
9. [x] When your links are clicked, the color should change to another color of your choice.

_Note_: Be sure to link your stylesheet in your HTML and apply your CSS.
