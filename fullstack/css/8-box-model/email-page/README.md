# Build a Confidential Email Page

Build an app that is functionally similar to this example project. Try not to copy the example project, give it your own personal style.

**Objective**: Fulfill the user stories below and get all the tests to pass to complete the lab.

## User Stories:

1. [x] You should have a main element with an id of email.
2. [x] Your #email element should have padding of 50px, a top margin of 50px, a width of 500px, and a border that's 2px.
3. [x] The total width of your #email element, including paddings and borders, should be 500px.
4. [x] You should have two div elements, one with an id of confidential and the other with an id of top-secret, within your #email element.
5. [x] Your #confidential and #top-secret elements should have a display of inline-block.
6. [x] Your #confidential and #top-secret elements should have a padding, a left margin, and a border.
7. [x] The #confidential element should have the text CONFIDENTIAL.
8. [x] The #top-secret element should have the text TOP SECRET.
9. [x] Your #confidential and #top-secret elements should be rotated using a CSS transform.
10. [x] You should have at least three paragraph elements within your #email element.
11. [x] You should have at least three span elements with a class of blurred, within your paragraph elements.
12. [x] You should have a blurred selector that blurs the element 3px using a CSS filter.
